# Workflow: Initialize Context

**Trigger:** Start of any new development session or context reset.

**Action Required:**

1. Review `MILESTONES.md` (or `.agent/rules.md`) to verify the project phase and constraints.
2. Read the latest entries in `PROMPT_LOG.md` to identify the last completed atomic task and current state.

**Output Requirement:**

1. A concise 2–3 sentence summary of the current project state and immediate next deliverable.
2. A strict explicit confirmation to follow the "1–3 steps maximum" atomic execution rule, holding for user review before proceeding.
3. A direct prompt asking for the specific atomic task to begin.
